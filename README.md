# Proyecto 1º DAM

Proyecto del gimnasio desarrollado para las asignaturas de:

- Programación
- Lenguajes de Marcas
- Entornos de Desarrollo

## Contenido

El repositorio incluye:
- Aplicación Java de gestión de gimnasio
- Proyecto web de Lenguaje de Marcas
- Transformaciones XML y XSLT
- Documentación UML
- JavaDoc
- Evidencias de Scrum y SonarQube
